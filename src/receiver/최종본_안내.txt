Drone Voice 최종본 - UART 자동 설정 / 부팅 볼륨 100%

기존 설치: bash update.sh
새 설치: bash install.sh
설치 후 반드시 한 번 재부팅: sudo reboot

설치 및 업데이트 과정에서 UART 하드웨어를 켜고 시리얼 로그인 콘솔을 끕니다.
dialout 권한을 설정하고 기존 부팅 자동 실행 기능을 유지합니다.
부팅 후 감지되는 모든 출력 장치를 음소거 해제하고 볼륨 100%로 설정합니다.
나중에 연결되는 출력 장치에도 연결 시 한 번 같은 설정을 적용합니다.
음성 스트림도 기본 100%로 출력합니다. 100%를 초과하는 증폭은 하지 않습니다.
수신 중 사용자가 조절한 장치 볼륨을 계속 100%로 강제하지 않습니다.
재부팅/수신기 재시작/장치 재연결 시에는 다시 100%로 설정됩니다.
스피커 자체 물리 볼륨은 별도로 조절해야 할 수 있습니다.

Target SYS=1, COMP=191. 송신 플러그인은 기존 버전을 사용합니다.
기본 UART 장치는 /dev/serial0이며, UART 설정 적용에는 재부팅이 필요합니다.
Raspberry Pi 5의 GPIO UART 등 다른 포트 매핑은 보드별 별도 설정이 필요할 수 있습니다.
Bluetooth 재부팅 후 연결 문제에 대한 자동 복구는 포함하지 않습니다.

기존 /boot 또는 /boot/firmware 설정은 설치 폴더 system-backups에 최초 백업합니다.
제거 스크립트는 UART/자동 로그인/볼륨 등 OS 설정을 되돌리지 않습니다.
이번 변경은 모의 검사와 수신 자체 검사로 검증했으며 새 OS에서 실제 부팅 확인은 필요합니다.

호환성 수정: raspi-config의 get_serial/get_serial_hw 호출을 제거했습니다.
UART 설정 후 실제 부팅 설정 파일을 읽어 확인합니다.
이전 설치가 중간에 멈췄다면 새 폴더에서 bash install.sh를 다시 실행하세요.
기존 OS를 다시 초기화하거나 플러그인을 다시 설치할 필요는 없습니다.

자동 설치 개선: UART 질문/OK 확인 창과 설치 시작 엔터 대기를 제거했습니다.
UART는 부팅 설정 파일에 직접 적용하며 원래 파일을 백업합니다.
관리자 비밀번호는 계정 권한에 따라 입력이 필요할 수 있습니다.
완료 후 sudo reboot를 한 번 실행해야 UART 설정이 적용됩니다.
