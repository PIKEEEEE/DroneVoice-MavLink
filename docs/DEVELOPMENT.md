# 개발 이력과 검증 상태

## 2026-10-27~28 개발 흐름

1. Raspberry Pi용 16kHz mono Opus 디코더, 48kHz stereo 출력, heartbeat 및 UART 수신기를 구현했습니다.
2. 원본 송신 소스가 없을 때 헤더를 `<II`로 가정했으나, 업로드된 `DroneVoicePlugin.cs` 확인 후 `<BHIB`로 바로잡았습니다. 8바이트는 오류가 아니라 PTT 종료 제어 패킷입니다.
3. 입력·디코딩·음량을 표시하고 소리 테스트를 추가해 통신과 출력 문제를 분리했습니다.
4. 단일 Bluetooth 재생에서 시작해 AUX/USB/HDMI 출력 선택과 설치 GUI를 구현했습니다.
5. 모든 스피커 동시 재생을 위해 가상 sink/loopback 분배를 시도했지만 부팅 후 PTT 무음이 확인됐습니다. 단일 직접 출력이 정상임을 확인하고 스피커별 독립 재생 방식으로 전환했습니다.
6. 사용자 서비스·자동 로그인·linger를 설정해 부팅 자동 시작을 구현했습니다.
7. 진단에서 일반 MAVLink는 수신되지만 TUNNEL=0인 상태를 확인했고, 사용자가 Target SYS를 1로 수정한 뒤 수신/디코딩이 증가했습니다. 그 사실만으로 FC 설정 변경이 필요하다고 결론내리지 않았습니다.
8. AUX 정상 동작을 확인했습니다. Bluetooth는 재부팅 후 수동 재연결하면 정상화되는 제한이 남습니다.
9. 송신 플러그인 Windows 설치 EXE를 제작했습니다. 기존 파일 백업·복원, 의존성 충돌 보호와 해시 검사를 포함합니다.
10. 초기화된 Pi에서 `/dev/serial0` 부재가 확인되어 UART 자동 설정을 추가했습니다. raspi-config getter의 버전 차이와 확인 창 문제를 거쳐 UART 설정은 직접 부팅 파일에 적용하도록 수정했습니다.
11. 부팅/장치 연결 시 OS 볼륨 100% 및 음소거 해제를 추가했습니다. 최신 묶음은 `DroneVoice_AutoInstall.zip`입니다.

## 저장소 정리: 2026-10-31

최신 소스, 재빌드 절차, 송신/수신 설치 파일, 과거 설치 묶음과 보고서를 한 저장소로 정리했습니다. PDF 보고서는 2026-10-28 시점의 문서이며, 이후 UART/볼륨/자동 설치 변경은 이 문서와 README가 보완합니다.

## 이전 배포본

`dist/archive`는 개발 과정 재현·비교용입니다. 파일명이 Final이어도 최신이라는 뜻이 아닙니다. 신규 설치는 README의 최신 자동 설치 링크를 사용하세요. 초기 배포본의 오류와 제한은 수정 이력의 일부로 보존합니다.
