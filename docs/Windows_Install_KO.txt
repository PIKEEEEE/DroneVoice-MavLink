Drone Voice — Mission Planner 설치 프로그램

1. 미션 플래너를 완전히 종료합니다.
2. DroneVoice_MissionPlanner_Setup.exe를 실행합니다.
3. Windows 관리자 권한 확인을 허용합니다.
4. MissionPlanner.exe가 있는 설치 폴더를 확인하고 [설치 / 업데이트]를 누릅니다.
   기본 경로: C:\Program Files (x86)\Mission Planner
5. 미션 플래너를 실행합니다.
6. Drone Voice 창에서 Target SYS=1 / COMP=191로 설정합니다.
7. 마이크 레벨이 움직이는지 확인한 뒤 PTT를 누른 채 말합니다.

창이 안 보이면 Flight Data 지도에서 마우스 오른쪽 버튼 -> Drone Voice (PTT)...

이 설치 파일은 기존에 사용한 DroneVoicePlugin.cs v0.4.0 송신 코드를 포함합니다.
Opus 16kHz mono, 20ms, 12kbps; TUNNEL payload_type=32768.
기존 라즈베리파이 수신 최종본과 같은 패킷 형식입니다.
미션 플래너 자체는 포함하지 않으며 설치된 미션 플래너에 플러그인을 추가합니다.
현재 이 PC의 Mission Planner 어셈블리 버전 1.3.9384.38250 기준으로 빌드했습니다.
다른 버전은 호환 확인 없이 설치하지 않고 안내합니다.
Windows .NET Framework 4.8 환경을 기준으로 합니다.

필요한 DLL은 설치 EXE 안에 포함되어 인터넷 없이 설치할 수 있습니다.
미션 플래너 본체의 공용 DLL은 덮어쓰지 않습니다.
같은 라이브러리가 본체 폴더에 있으면 그대로 사용합니다.
다른 버전의 의존성 파일이 발견되면 충돌 방지를 위해 설치를 중단합니다.

이전 상태로 되돌리려면:
미션 플래너를 종료하고 같은 EXE의 [설치 전 상태 복원]을 누릅니다.
설치 당시 새로 추가한 DLL은 제거하고, 바꾼 플러그인은 백업에서 복원합니다.
기존 Drone Voice가 있었다면 해당 이전 버전으로 돌아갑니다.
설치 후 다른 프로그램이 변경한 파일은 자동으로 삭제/덮어쓰지 않습니다.
백업/설치 기록: Mission Planner\plugins\.dronevoice-setup
Windows 앱 목록에 별도의 제거 프로그램은 등록하지 않습니다. 설치 EXE를 보관하세요.

이 EXE는 코드 서명이 없어 Windows 보안 확인이 표시될 수 있습니다.
검증: EXE 생성, 포함 파일 해시, 임시 폴더 설치/재설치/복원,
변경 파일 보호, 공용 의존성 재사용/충돌 감지,
실제 .NET Framework Opus 20ms 인코딩/디코딩 검사 통과.
현재 미션 플래너 설치 폴더는 테스트 중 변경하지 않았습니다.
설치 후 미션 플래너에서의 실제 마이크/PTT 송신은 사용자 환경에서 확인이 필요합니다.
라이선스는 설치 화면의 [라이선스] 및 동봉 THIRD-PARTY-NOTICES.txt를 참고하세요.
